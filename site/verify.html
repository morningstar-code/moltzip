Verify your download

MoltZip is only distributed from github.com/morningstar-code/moltzip/releases and this site. It works only with files on your computer and does not use the network: it has no networking code and no networking library. Before a release is published, its build checks that the programs import no networking or socket library.

The release files are not code-signed yet, so Windows SmartScreen and some antivirus engines that score new, unsigned programs by machine learning may warn about them. To check that a file is the one published here, compare its checksum.

Compare the checksum

Every release file has a .sha256 file next to it, and the table below lists them. Compute the file's SHA-256 and compare.

Windows, in PowerShell:

Get-FileHash .\MoltZip-x64-setup.exe -Algorithm SHA256

macOS:

shasum -a 256 MoltZip-aarch64.dmg

Linux:

sha256sum MoltZip-x86_64.AppImage
